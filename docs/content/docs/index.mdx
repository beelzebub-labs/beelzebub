## Choose Your Path

- **Security operators:** install, configure, expose, monitor, and safely retire decoys.
- **AI security teams:** deploy MCP tripwires and LLM-powered interactions to measure agent guardrail bypasses.
- **Developers:** use the public plugin SDK, add protocols, and keep schemas, validators, tests, and docs aligned.

<Callout type="warn" title="Use only on systems you are authorized to monitor">
  Honeypots intentionally collect attacker input and may expose sensitive data through logs, queues, cloud integrations, or LLM providers. Begin in an isolated lab and read the production safety guide before internet exposure.
</Callout>
